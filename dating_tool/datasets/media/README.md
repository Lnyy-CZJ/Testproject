# 私密测试媒体目录

只放人工确认已脱敏或本地合成的测试截图。该目录内容默认不进入 Git；工具只读校验并
原样上传，不负责编辑、生成或自动脱敏生产数据。

要求：

- 仅使用 `.png`、`.jpg/.jpeg` 或 `.webp`，扩展名必须与真实格式一致；
- 删除 EXIF，并人工检查姓名、头像、账号、地点、时间和其他个人信息；
- 单图/多图顺序由 Case 中 `media` 数组决定，不依赖文件名或拍摄时间；
- 不要使用生产用户截图；本地合成素材建议使用安全英文对话；
- `staging-analysis-smoke.png` 是本机一次性生成的 Analysis 单图 Fixture，不进入 Git；
- `reply-single-01.png`、`reply-multi-01.png` 等名称只用于本地模板，需由执行者补齐。
