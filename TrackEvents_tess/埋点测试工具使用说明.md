# 埋点测试工具使用说明

## 启动

在当前目录执行：

```bash
python3 trackevents_web.py
```

启动成功后，终端会显示：

```text
埋点测试工具已启动: http://127.0.0.1:8000
```

浏览器打开：

```text
http://127.0.0.1:8000
```

## 使用

1. 点击“上传 log 文件”，选择客户端导出的 `.log` 或 `.txt` 文件。
2. 如需判断触发次数是否正确，在“预期触发次数 JSON”中填写事件名和预期次数。
3. 点击“开始解析”。
4. 查看结果页签：
   - 事件统计：查看每个 Action 的实际触发次数和预期次数校验。
   - 事件明细：查看每条事件的字段校验结果。
   - 响应校验：查看每个 TrackEvents 请求的 `accepted_count` 是否正确。
   - 报告文本：查看 Markdown 格式报告。
5. 点击“下载 Markdown 报告”可导出报告。

## 预期次数 JSON 示例

```json
{
  "app_foreground": 1,
  "app_page_stay": 3,
  "lead_leave_dialogview": 1,
  "lead_leave_leave_click": 1,
  "lead_page_exit": 1
}
```

## 说明

- 工具只解析 `method=TrackEvents` 的请求与响应。
- 其他请求，例如 `RefreshSession`，会被自动忽略。
- 一个 TrackEvents 请求中包含多条事件时，工具会逐条展开统计。
- 事件规则按 `测试埋点功能PRD.md` 中的 1.0.0 埋点清单维护在 `trackevents_core.py`。
- 当前版本不依赖 Flask 等第三方 Web 框架，使用 Python 标准库即可运行。
