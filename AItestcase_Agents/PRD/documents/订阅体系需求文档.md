
### 1.2 核心流程链路

```
任意入口触发订阅页
    │
    ▼
订阅页（方案选择 + 权益展示）
    │
    ├── 点击「Unlock Full Report」
    │       ├── 拉起系统订阅支付流程
    │       ├── 校验过程中展示 Loading
    │       │
    │       ├── 支付成功 → 弹出成功弹窗 → 关闭订阅页 → 返回触发页 → 解锁全部权益
    │       └── 支付失败/取消 → 弹出失败 toast → 停留在订阅页
    │
    ├── 点击「×」关闭 → 返回上一个页面，不改变拦截状态
    │
    └── 点击「Restore」→ 恢复购买校验 → 返回结果
```

## 二、订阅页触发入口

### 2.1 入口总览

| 编号  | 入口位置                                                 | 触发条件       | 说明                       |
| --- | ---------------------------------------------------- | ---------- | ------------------------ |
| 1   | **首页** 右上角 pro 入口                                | 用户非VIP | 点击首页右上角 pro 入口           |
| 2   | **首页** 检索案例页                                 | 用户非VIP | 案例报告页内点击订阅拦截部分 |
| 3   | **首页** 用户非VIP 进入历史记录页                    | 用户非VIP     | 点击任意的历史记录/历史报告页内点击订阅拦截部分  |
| 4   | **首页** 点击检索框 → 用户非VIP 输入线索后点击 search | 用户非VIP     | 被订阅页拦截               |
| 5   | **首页** 个人中心                                  | 用户非VIP | 点击「订阅 banner」        |

### 2.2 拦截规则

- 以上所有入口在用户**非VIP状态**下点击时，均被**订阅页拦截**
- 订阅页为**模态页面**，覆盖在当前页面之上
- 用户完成订阅或主动关闭后，返回触发时的页面

## 四、订阅页交互逻辑

### 4.1 订阅方案选择

| 规则       | 说明                             |     |
| -------- | ------------------------------ | --- |
| **默认选中** | "订阅方案" 且外露 **MOST POPULAR** 标签 |     |
| **切换方案** | 用户可切换至 "订阅方案"                  |     |
| **选中状态** | 选中方案右侧显示 ✓ 勾选标记                |     |

### 4.2 点击「Unlock Full Report」

| 步骤 | 行为 |
|------|------|
| 1. 点击按钮 | 拉起**系统订阅支付**（Apple IAP） |
| 2. 校验过程 | 展示 **Loading** 动画（"Subscribing..."） |
| 3a. 支付成功 | 关闭订阅页面，返回触发时的页面，并**解锁全部订阅权益** |
| 3b. 支付失败/取消 | 停留在订阅页，弹出**报错 toast** |

### 4.3 点击「×」关闭页面

| 行为      | 说明                          |
| ------- | --------------------------- |
| 返回上一个页面 | 且**不改变**当前已拦截的内容状态/已填写的内容状态 |
| 用户可再次触发 | 用户仍可再次触发订阅页                 |

### 4.4 点击「恢复购买」

| 行为   | 说明                                          |
| ---- | ------------------------------------------- |
| 功能   | 当用户卸载重装或换设备登录，需通过"恢复购买"按钮还原 VIP 状态          |
| 入口位置 | 建议在**设置项**增加 恢复购买 入口                     |
| 校验过程 | 展示 **Loading** 动画（"Restoring purchases..."） |

### 4.5 用户 App Store 取消订阅

在订阅成功后，去App Store 取消订阅，app更新订阅状态

## 五、恢复购买流程

### 5.1 触发场景

- 用户**卸载重装**，需通过"恢复购买"按钮还原 VIP 状态

### 5.2 恢复购买校验结果

| 结果                   | 行为                                                          |
| -------------------- | ----------------------------------------------------------- |
| **1. 在订阅状态时间内、恢复成功** | 关闭订阅页面，返回触发时的页面                                             |
|                      | Toast 提示："✅ Your purchases have been restored successfully" |
| **2. 未订阅或订阅过期**      | 弹出 toast，停留在订阅页面                                            |
|                      | Toast 提示："️ No active purchases found."                     |
| **3. 其他异常错误**        | 弹出 toast，停留在订阅页面                                            |
|                      | Toast 提示："⚠️ Failed to restore purchases. Please retry."    |

## 六、订阅成功/失败处理

### 6.1 订阅成功

| 步骤        | 行为                                         |
| --------- | ------------------------------------------ |
| 1. 弹出订阅弹窗 | 关闭订阅页面，返回触发时的页面                            |
| 2. 弹窗内容   | 成功插画 + "Subscription successful" + "OK" 按钮 |
| 3. 点击 OK  | 关闭弹窗，权益生效                                  |

### 6.2 订阅取消/失败

| 行为 | 说明 |
|------|------|
| 弹出订阅失败 toast | 停留在订阅页面 |
| Toast 文案 | "⊘ Subscription failed, please retry." |

## 十、页面流转关系（订阅完整链路）

```
任意入口（非VIP）
 └── 点击触发
      │
      ▼
 ┌─────────────────────────────────────┐
 │            订阅页（模态拦截）           │
 │                                     │
 │  ├── × 关闭 → 返回上一页（保留状态）    │
 │  ├── Restore → Loading → 恢复结果     │
 │  │     ├── 成功 → 关闭订阅页 → 返回     │
 │  │     ├── 未找到 → toast → 停留       │
 │  │     └── 异常 → toast → 停留         │
 │  │                                   │
 │  ├── 方案选择（Weekly / Annual）       │
 │  │                                   │
 │  └── Unlock Full Report              │
 │        ├── Loading（Subscribing...）   │
 │        ├── 成功 → 成功弹窗 → OK        │
 │        │       → 关闭订阅页 → 返回触发页 │
 │        │       → 解锁全部权益            │
 │        └── 失败 → toast → 停留订阅页    │
 └─────────────────────────────────────┘

订阅成功后权益生效：
 ├── 案例/历史报告页 → 遮照去除，可查看完整报告
 ├── 首页 订阅 入口 → 点击弹出「已订阅状态弹窗」（含到期日期）
 ├── 触发检索 → 真实 Deep Search（非假加载）
 └── 个人中心 banner → 变为「订阅中状态」（含到期日期）
```
