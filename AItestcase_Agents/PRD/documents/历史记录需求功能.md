
### 2.1 历史记录页入口

| 入口位置         | 触发条件       | 说明         |
| ------------ | ---------- | ---------- |
| **首页** 顶部导航栏 | 点击历史查询记录入口 | 跳转至「历史记录页」 |

### 2.2 历史记录列表规则

| 规则         | 说明                       |
| ---------- | ------------------------ |
| **保留时长**   | 保留 **6个月** 历史记录          |
| **排序方式**   | 按照查询时间由新至旧排序             |
| **列表内容**   | 展示人物姓名 + 基础信息（头像、职业、位置等） |
| **点击行为**   | 点击任一条历史记录 → 跳转至对应「个人结果页」 |
| **外露日期格式** | 「**月·日**」，如 "Jan 15"     |

### 2.3 历史记录页 → 结果页的模块展示逻辑

从历史记录进入结果页时，根据用户VIP身份展示不同内容：

#### 2.3.1 非VIP

| 模块 | 展示状态 | 说明 |
|------|---------|------|
| **社交账号**（社交账号） | ✅ 正常展示 | 浅层查询数据，直接展示 |
| **Photo Analysis**（照片分析） | 🔒 **锁定** | 展示锁定遮罩 + "Photo Analysis is locked" + "Unlock advanced photo insights and identity verification." + 「**Unlock Premium**」按钮 |
| **人物档案**（人物档案） | ✅ 正常展示 | 浅层查询数据，直接展示 |
| **检索加载页**（深度调研） | 🔒 **锁定** | 展示锁定遮罩 + "检索加载页 is locked" + "Unlock relationship insights, career history, public records, and potential risk indicators." + 「**Unlock Premium**」按钮 |

**锁定模块交互：**
- 点击「**Unlock Premium**」按钮 → 跳转至「**订阅页**」
- 订阅后 → 解锁全部模块，正常查看全部报告内容

#### 2.3.2 VIP

| 模块 | 展示状态 | 说明 |
|------|---------|------|
| **社交账号** | ✅ 正常展示 | — |
| **Photo Analysis** | ✅ 正常展示 | 正常查看全部照片分析内容 |
| **人物档案** | ✅ 正常展示 | — |
| **检索加载页** | ✅ 正常展示 | 正常查看全部深度调研内容 |

> VIP可正常查看全部报告内容，无锁定遮罩。
