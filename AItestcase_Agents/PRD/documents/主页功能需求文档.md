
## 主页功能需求

### 2.1 页面布局与入口

#### 2.1.1 顶部导航栏

| 入口       | 说明                           |
| -------- | ---------------------------- |
| 历史查询记录入口 | 点击跳转「历史纪录页」                  |
| 订阅入口     | 未订阅用户：跳转「订阅页」；已订阅用户：弹出「订阅说明」 |
| 个人中心入口   | 点击跳转「个人中心」                   |

#### 2.1.2 品牌背书区域

- **展示**：IP + Slogan（or IP + APP名）
- **视觉**：建立情感感 + 品牌记忆点

#### 2.1.3 搜索入口

- 点击自然过渡至「线索页」

#### 2.1.4 主页（预制信息）

**展示内容：**
- 预制4组（产品提供配置信息）
- 头像、姓名
- 社交账号个数：≤3个（外露平台 icon）+3个额外展示（+N）

#### 2.1.5 用户故事（预制信息，无交互）

**展示内容：**
- 预制3组（产品提供配置信息）
- 头像、年龄、故事描述（三行）

### 2.2 主页核心区域

| 元素 | 说明 |
|------|------|
| Slogan | "Before you trust them, **Truthy them.**" |
| 首页 | 占位文案："Enter full name to trail..."，点击跳转线索页 |
| Popular people | 展示热门人物头像（如 Elon Musk、Lady Gaga、Cristiano Ronaldo、Kyle Jenner 等） |
| Stories from Truthy users | 用户故事卡片，展示头像、年龄、故事摘要 |
