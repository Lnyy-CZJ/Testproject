
## 二、评分弹窗触发时机

### 2.1 用户行为自动触发

#### 2.1.1 触发条件配置

| 配置项                   | 说明                 | 默认值     |
| --------------------- | ------------------ | ------- |
| **enabled 开关**        | 控制评分总开头，默认为开       | 开       |
| **trigger_event**     | 触发评分条件事件           | 见下方事件列表 |
| **min_app_version**   | 最低版本要求             | V1.0.0  |
| **cool_day**          | 两次评分弹窗最小间隔天数       | 14天     |
| **max_total_prompts** | 每个设备/用户生命周期内最多提示次数 | 3次      |

#### 2.1.2 触发事件列表（trigger_event）

| 事件                  | 说明                  | 默认N值           |
| ------------------- | ------------------- | -------------- |
| **首次完成检索**          | 触发检索单一人物报告页时        | —              |
| **APP启动次数累计达到N次**   | APP首次启动后经过N天        | N=5, 10（多值）    |
| **查看单一人物报告页累计达到N次** | 包含线索页/历史单一人物报告页/案例页 | N=1, 5, 10（多值） |

#### 2.1.3 防骚扰规则

| 规则        | 说明                               |
| --------- | -------------------------------- |
| **冷却期**   | 两次评分弹窗最小间隔 **2天**                |
| **次数上限**  | 每个设备/用户生命周期内最多提示 **3次**          |
| **已提交豁免** | 已提交过评分/反馈的用户，生命周期内**不再触发**任何评分引导 |

### 2.2 用户主动点击

| 入口          | 位置         | 说明         |
| ----------- | ---------- | ---------- |
| **Rate Us** | 个人中心（个人中心） | 点击直接触发评分弹窗 |


## 三、评分弹窗内容及交互

### 3.1 评分弹窗

#### 3.1.1 弹窗内容

| 元素   | 说明                                                                                  |
| ---- | ----------------------------------------------------------------------------------- |
| 标题   | "We'd love to hear your thoughts!""How would you rate your experience with Truthy?" |
| 评分组件 | 1-5星选择（默认未选中，Submit按钮置灰）                                                            |
| 提交按钮 | "Submit"（至少选择1星后可点击）                                                                |
| 关闭按钮 | 右上角 ×，点击关闭弹窗，保持弹窗前的界面                                                               |

#### 3.1.2 交互规则

| 规则 | 说明 |
|------|------|
| **默认状态** | 星星未选中，Submit按钮**置灰不可点** |
| **选择1-2星** | Submit按钮**可点击**，点击后跳转 Feedback页 Feedback页 |
| **选择3-5星** | Submit按钮**可点击**，点击后弹出系统评分弹窗 |
| **点击关闭（×）** | 关闭弹窗，保持弹窗前的界面 |

### 3.2 反馈引导弹窗（1-4星）

#### 3.2.1 弹窗内容

| 元素   | 说明                                                |
| ---- | ------------------------------------------------- |
| 标题   | "We'd love to hear your thoughts!"                |
| 副标题  | "How would you rate your experience with Truthy?" |
| 评分组件 | 1-4星已选中（高亮显示）                                     |
| 提交按钮 | "Submit"（可点击）                                     |

#### 3.2.2 交互行为

- 点击「**Submit**」→ 跳转至 **Feedback页**

### 3.3 系统评分弹窗（5星）

#### 3.3.1 弹窗内容

| 元素   | 说明                                        |
| ---- | ----------------------------------------- |
| 标题   | "Enjoying Facuser?"                       |
| 副标题  | "Tap a star to rate it on the App Store." |
| 评分组件 | 5星选择                                      |
| 取消按钮 | "Cancel"                                  |
| 提交按钮 | "Submit"                                  |

#### 3.3.2 交互行为

| 操作             | 行为                                              |
| -------------- | ----------------------------------------------- |
| 点击「**Submit**」 | 跳转 **App Store 评分页面**（需跳转App Store评分页面并支持返回APP） |
| 点击「**Cancel**」 | 关闭弹窗                                            |

#### 3.3.3 异常处理

- 若系统引导评分弹窗**无法调起**，直接跳转**应用商店评分页面**

## 四、Feedback页

### 4.1 页面布局

| 元素      | 说明                                                                         |
| ------- | -------------------------------------------------------------------------- |
| 返回按钮（←） | 左上角                                                                        |
| 页面标题    | "Feedback页"                                                                |
| 提示文案    | "How can we help you?"                                                     |
| 文本输入框   | 占位文案："Please share your concern or describe the issue you're experiencing" |
| 照片上传    | 上传照片                                                                       |
| 提交按钮    | "Submit"（文字框不为空时可点击）                                                       |

### 4.2 交互规则

| 规则            | 说明                        |
| ------------- | ------------------------- |
| **默认状态**      | 文本框为空，Submit按钮**置灰**      |
| **输入内容**      | 文字框不为空时，Submit按钮**可点击**   |
| 点击照片上传按钮      | 上传照片                      |
| **点击 Submit** | 提交反馈 → 自动返回触发前页面 → 弹出成功提示 |
| **点击返回（←）**   | 返回触发前页面                   |

### 4.3 提交成功处理

| 行为             | 说明                                             |
| -------------- | ---------------------------------------------- |
| 提交 Feedback页 后 | **自动返回**触发前页面                                  |
| 成功提示           | 弹出 toast："✅ Thank you for helping us improve!" |
| 弹窗消失           | 自动消失                                           |
