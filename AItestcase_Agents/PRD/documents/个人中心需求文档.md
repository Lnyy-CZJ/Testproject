## 五、Feedback页（反馈）

### 5.1 入口与页面

| 元素 | 说明 |
|------|------|
| 入口位置 | 个人中心 GENERAL 菜单 → Feedback页 |
| 页面标题 | "Feedback页" |
| 返回按钮 | 左上角返回箭头 |

### 5.2 页面布局

| 区域 | 元素 | 说明 |
|------|------|------|
| **反馈输入框** | 标题 | "* How can we help you?" |
| **反馈输入框** | 文本域 | 占位文案："Please enter your advice or describe the problem you encountered." |
| **图片上传区** | 标题 | "Image" |
| **图片上传区** | 上传按钮 | "+" 号按钮 |
| **图片上传区** | 已上传图片 | 缩略图展示 + 删除按钮 |
| **联系方式输入框** | 提示文案 | "If you need any help, please leave your email address, we will contact you as soon as possible." |
| **联系方式输入框** | 输入框 | 占位文案："Your Email Address (Optional)" |
| **提交按钮** | Submit | 底部「Submit」按钮 |

### 5.3 反馈输入框规则

| 规则       | 说明                  |
| -------- | ------------------- |
| **字符限制** | 最多输入 **500个字符**     |
| **超出限制** | 字符达到500之后**无法继续输入** |
| **必填标识** | 标题前有 "*" 号，表示必填     |

### 5.4 图片上传规则

| 规则       | 说明                |
| -------- | ----------------- |
| **支持操作** | 支持**上传/删除**已上传图片  |
| **数量限制** | 最多上传 **5张图片**     |
| **超出限制** | 已上传5张后只能删除，添加入口隐藏 |
### 5.5 联系方式输入框规则

| 规则       | 说明             |
| -------- | -------------- |
| **格式限制** | 本期**不限制格式**    |
| **字符限制** | 最多输入 **50个字符** |
| **必填性**  | 选填（Optional）   |

### 5.6 Submit 按钮规则

| 状态 | 条件 | 按钮状态 |
|------|------|---------|
| **置灰不可点** | 反馈输入框为**空**时 | 置灰 |
| **可点击** | 反馈输入框**不为空**时 | 可点击 |

#### 特殊规则：反馈输入框为空只有空格内容时

| 场景             | 行为                                 |
| -------------- | ---------------------------------- |
| 反馈输入框只有**空格**时 | 点击后仍停留在Feedback页面，弹出toast提示        |
| Toast文案        | "️ Please enter feedback content." |

### 5.7 提交成功处理

| 行为        | 说明                                            |
| --------- | --------------------------------------------- |
| **提交成功后** | 返回进入Feedback页之前的页面                            |
| **成功提示**  | 弹出toast："✅ Thanks for helping us get better!" |
