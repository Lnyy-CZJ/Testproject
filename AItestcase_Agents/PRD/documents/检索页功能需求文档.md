
## 三、线索页（检索页）功能需求

### 3.1 页面状态

线索页存在三种状态：

| 状态       | 说明                                    |
| -------- | ------------------------------------- |
| **收起状态** | 未添加补充线索，仅展示首页 + 照片推荐卡片             |
| **收起状态** | 已添加补充线索，展示首页+已添加的线索（未添加的线索不展示） |
| **展开状态** | 已添加补充线索，展示全部线索（照片、社交链接、位置、职业及其他信息）  |

### 3.2 线索页交互逻辑

#### 3.2.1 页面触发路径 & 条件

- 主页点击搜索框，从主页渐进过渡到「线索页」，同时自动拉起键盘
- 名字搜索框吸顶，外显「更多线索按钮入口」
- 默认收起更多线索按钮

#### 3.2.2 照片推荐卡片

**展示条件**（线索页内判断以下条件**同时满足**，则触发展示，淡入出现）：

1. 姓名线索框输入 **≥2个单词**
2. 「更多线索」为**收起状态**
3. **未添加任何**「更多」线索

#### 3.2.3 已添加补充线索展示

**展示条件**（线索页内判断以下条件**同时满足**，则触发展示）：

1. 「更多线索」为**收起状态**
2. 添加至少1条「更多」线索

#### 3.2.4 更多线索展开/收起

| 场景 | 默认状态 |
|------|---------|
| 每次首页进入线索页时 | 默认**收起** |
| 候选人页返回线索页时 | 默认**展开** |
| 点击切换 | 手动切换状态 |

#### 3.2.5 搜索按钮

| 条件              | 状态                                                      |
| --------------- | ------------------------------------------------------- |
| 姓名线索输入 **≥2字符** | 置为**可点击**，不满足条件则搜索按钮置灰                                  |
| 点击后             | 判断用户是否为VIP：非VIP则走「提交线索 → 候选集生成流程」；VIP则走「提交线索 → 候选集生成流程」 |

#### 3.2.6 返回按钮

| 条件             | 行为         |
| -------------- | ---------- |
| 判断全部线索填充为**空** | 直接返回至首页    |
| 判断**任一**线索非空   | 弹出「二次确认弹窗」 |

**二次确认弹窗：**
- 文案："Leave this search? Your clues will be lost if you leave now."
- 点击「**Stay**」→ 停留「线索页」
- 点击「**Leave**」→ 返回首页，并清除本次已填充线索信息

## 四、线索规则

### 4.1 字段总览

| 线索类型        | 数据类型                                                              | 用户必选/可选 | 验证规则                                  |
| ----------- | ----------------------------------------------------------------- | ------- | ------------------------------------- |
| **全名**      | 文本（First+Last Name）                                               | **必选**  | 至少包含2个单词，每个≥2字符，拒绝带有数字和单一字符，特殊符号做屏蔽处理 |
| **照片**      | 相册图片（≤3张）                                                         | 可选      | 检测是否含人脸，≤10MB/张                       |
| **位置**      | 文本描述（自行解析为城市/州/国家字段）                                              | 可选      | 自由文本，用本地解析城市/州/国家三级核心结构               |
| **已知社交URL** | 用户输入URL链接（LinkedIn / Instagram / Facebook / YouTube / X / TikTok） | 可选      | 校验链接格式；校验域名是否属于指定平台                   |
| **其他补充**    | 文本（引导填写：职业/公司/学校等）                                                | 可选      | 自由文本，用轻量级关键词提取（公司/学校/职位/邮箱/电话等）       |

## 五、线索输入交互

### 5.1 文本类型线索

#### 5.1.0 姓名输入框基本交互规则

- 点击拉起键盘；
- 空输入显示灰字提示
- 非空时展示「一键清除按钮」，点击清除框内文字

#### 5.1.1 姓名（必填）

| 规则 | 说明 |
|------|------|
| 输入 ≥2字符 | 允许 Search |
| 最多支持输入 | 50个字符，超出自截断 |

#### 5.1.2 社交账号 URL Link（选填，支持添加多个）

**添加链接：**
- 「线索页」每次点击「Add Link」时判断，符合规则则添加成功，否则弹 toast 报错
- 可匹配平台：**LinkedIn、Instagram、Facebook、YouTube、Twitter(X)、TikTok**
- 添加成功时自动判断所属社交平台展示平台 icon 标识
- 若输入为空，则弹 toast「**空报错**」
- 若链接不符合任一平台域名规则，则 toast 提示「**链接无效报错**」

**删除链接：**
- 点击一已添加链接旁「X」删除

#### 5.1.3 位置（选填）

- 最多支持输入 **100个字符**，超出自动截断

#### 5.1.4 其他信息（选填）

- 最多支持输入 **500个字符**，超出自动截断

---

### 5.2 图片类型线索

#### 5.2.1 照片（选填，支持添加多个）

**添加照片：**
- 「线索页」每次「上传照片」直接拉起系统弹窗，让用户选择1张照片
- 系统未授权上传照片时，上传失败
- 系统已授权上传照片时，上传成功
- 最多添加「**3张照片**」，超出则隐藏「照片添加」入口
- 每次上传1张照片时，判断图片大小，若不超过10MB则添加成功，否则 toast 报错
- 检查图片是否只包含一张人脸
	   - 是：上传成功
	   - 否：上传失败

**删除照片：**
- 已添加照片展示「删除 icon」，点后直接删除

## 六、页面流转关系

```
首页
 ├── 点击姓名搜索框 ──→ 线索页（收起状态，自动拉起键盘）
 │                        ├── 输入姓名 ≥2字符 ─→ 搜索按钮可点击
 │                        ├── 输入姓名 ≥2单词 + 收起状态 + 无更多线索 ──→ 照片推荐卡片淡入展示
 │                        ├── 添加补充线索 ──→ 线索页展开状态
 │                        ├── 点击 Search ──→ 候选集页
 │                        ── 点击返回 ──→ 首页（有内容则弹二次确认）
 │
 ├── 点击搜索案例 ──→ 线索页（预填信息）
 ├── 点击历史查询记录 ──→ 历史纪录页
 ├── 点击订阅入口 ──→ 订阅页 / 订阅说明弹窗
 └── 点击个人中心 ──→ 个人中心页

候选集页
 └── 返回 ──→ 线索页（展开状态，保留已填线索）
```
