报告问题交互逻辑

### 10.1 触发入口

- 页面右上角「**Issue**」按钮
- 点击后拉起「报告问题弹窗」

### 10.2 弹窗内容

#### 10.2.1 预设问题选项

弹窗标题："报告问题 — 选择最能描述错误问题的选项："

| 选项 | 说明 |
|------|------|
| 信息错误 | — |
| 不可靠源 | — |
| 侵犯隐私 | — |
| 攻击性内容 | — |
| 偏见 / 歧视 | — |
| 图片质量低 | — |
| 身份识别错误 | — |
| 算法错误 | — |
| 垃圾信息 | — |
| 其他 | 选择后拉起文本输入框和键盘 |

#### 10.2.2 交互规则

| 规则 | 说明 |
|------|------|
| **默认状态** | 弹窗内默认**不选中**选项，提交按钮**置灰** |
| **选择预设问题** | 点击「预制问题」选项，提交按钮置为**可点击** |
| **提交预设问题** | 提交后弹出「提交成功」toast，反馈信息汇总至数据库 |
| **选择「其他选项」** | 拉起文本输入框和键盘 |
| **自定义输入** | 输入内容不超过 **500字**，超出截断 |
| **提交按钮状态** | 为空时提交按钮**置灰**，非空时可点击 |
| **提交自定义内容** | 提交后弹出「提交成功toast」，反馈信息汇总至数据库 |

### 10.3 提交结果处理

| 结果 | 行为 |
|------|------|
| **提交成功** | 弹出 toast："✅ Submitted successfully. Thanks for your feedback." → 返回单一人物报告页 |
| **提交失败** | 弹出 toast："⊘ Submission failed. Please try again." → 保持反馈弹窗拉起 |

### 10.4 自定义问题描述页

| 元素 | 说明 |
|------|------|
| 返回按钮（←） | 左上角 |
| 页面标题 | "报告问题" |
| 副标题 | "选择最能描述错误问题的选项：" |
| 文本输入框 | 占位文案："在这里输入您的报告" |
| 提交按钮 | 底部「提交」按钮 |
