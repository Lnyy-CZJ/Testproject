# 用户管理与云效认证边界修复设计

## 目标
修复用户管理列表信息不准确、重置密码重复点击、项目 Webhook 操作区换行，以及云效联调错误误伤系统登录态的问题。

## 范围
1. 用户模型新增最近登录时间字段。
2. 登录成功后写入最近登录时间。
3. 用户管理列表删除密码状态，改为最近登录时间。
4. 重置密码增加行级 loading，避免重复触发。
5. 项目 Webhook 操作区按钮保持单行。
6. 云效第三方 401/403 不再映射为系统会话 401。
7. 前端只在明确 JWT 失效时清理登录态并跳转登录页。

## 关键决策
- 最近登录时间历史为空时展示“未登录”，不做伪造回填。
- 云效第三方凭证错误使用业务错误返回，不再使用 HTTP 401，以避免前端误判为当前系统登录失效。
- 前端鉴权拦截器收紧为：仅对登录态失效类报错执行登出与跳转。
