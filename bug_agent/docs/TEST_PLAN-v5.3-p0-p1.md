# BugAgent v5.3 测试计划（P0 + P1）

> Date: 2026-04-18  
> Scope: `PRD-v5.3` P0 + P1  
> 基于文档: `PRD-v5.3-intelligent-operations-and-hardening.md` / `DESIGN-v5.3-p0-p1.md`

---

## 1. 测试范围

### P0

1. 全站搜索/筛选栏统一与样式回归。
2. Webhook 签名校验（安全链路）。

### P1

1. 智能推荐分配 v1。
2. AGENT 自动推荐 v1。

---

## 2. 测试策略

1. 单元测试：评分逻辑、验签函数、组件渲染逻辑。
2. 集成测试：接口参数、权限、审计日志、错误码。
3. E2E 测试：核心页面筛选栏行为、推荐交互、一键采纳。
4. 人工冒烟：视觉一致性与真实操作链路。

---

## 3. 关键测试用例（按模块）

## 3.1 P0-UI 统一筛选/搜索栏

### 自动化

1. `UI-FILTER-01` 缺陷管理搜索框无空白按钮、无双边框。
2. `UI-FILTER-02` 问题池搜索框样式与缺陷管理一致。
3. `UI-FILTER-03` 回归预防搜索框样式一致。
4. `UI-FILTER-04` 用户管理搜索框样式一致。
5. `UI-FILTER-05` 审计日志筛选栏布局一致。

### 人工

1. `UI-FILTER-M01` 各页面缩放 90%/100%/125% 无错位。
2. `UI-FILTER-M02` 页面切换后筛选栏无抖动与溢出。

验收标准：

1. 核心页面全部 PASS，无视觉阻塞项。

---

## 3.2 P0-Webhook 签名校验

### 自动化

1. `SEC-WEBHOOK-01` 合法签名请求返回成功。
2. `SEC-WEBHOOK-02` 错误签名返回 401/403。
3. `SEC-WEBHOOK-03` 缺失签名返回 401/403（强校验开启）。
4. `SEC-WEBHOOK-04` 签名失败写入审计日志。
5. `SEC-WEBHOOK-05` 测试模式关闭强校验时请求可通过。

### 人工联调

1. `SEC-WEBHOOK-M01` 使用外部脚本生成签名联调通过。
2. `SEC-WEBHOOK-M02` 错误 secret 联调被拦截并给出可读错误。

验收标准：

1. 非法签名拦截率 100%，无绕过路径。

---

## 3.3 P1-智能推荐分配

### 自动化

1. `REC-ASSIGN-01` 返回 Top-N 推荐用户（默认 Top-3）。
2. `REC-ASSIGN-02` 推荐结果包含评分与理由。
3. `REC-ASSIGN-03` 高负载用户降权生效。
4. `REC-ASSIGN-04` 无历史数据时回退到规则默认推荐。
5. `REC-ASSIGN-05` 一键采纳推荐后指派成功。

### 人工

1. `REC-ASSIGN-M01` 对典型缺陷类型推荐结果符合预期。
2. `REC-ASSIGN-M02` 采纳/不采纳行为可在日志或统计中看到。

验收标准：

1. 推荐接口稳定可用；推荐可解释；采纳链路可追踪。

---

## 3.4 P1-AGENT 自动推荐

### 自动化

1. `REC-AGENT-01` 不同缺陷类型返回对应推荐 AGENT 列表。
2. `REC-AGENT-02` 推荐列表包含置信度与理由。
3. `REC-AGENT-03` 手动覆盖推荐后创建/分析流程正常。
4. `REC-AGENT-04` 覆盖行为记录成功。

### 人工

1. `REC-AGENT-M01` UI 可见推荐理由，文案可读。
2. `REC-AGENT-M02` 推荐与最终执行 AGENT 一致可追溯。

验收标准：

1. 推荐准确性达到可用水平（先可用、后优化）。

---

## 4. 回归测试清单（必须）

1. 登录、项目切换、迭代切换不受影响。
2. 缺陷创建、缺陷详情、评论、分析、修复链路不受影响。
3. 问题池筛选、路由治理、回归预防、质量情报可正常加载。
4. 通知中心、个人中心、用户管理核心操作可用。

---

## 5. 执行计划

### 阶段 A（迭代 5.3.1）

1. 先跑 UI 自动化 + 人工视觉巡检。
2. 回归问题当迭代内清零，不带到下一迭代。

### 阶段 B（迭代 5.3.2）

1. 验签单测与集成测试先过。
2. 再做外部联调。

### 阶段 C（迭代 5.3.3）

1. 推荐算法测试 + 前端交互测试。
2. 最后跑全链路回归。

---

## 6. 通过标准（Go/No-Go）

1. P0 用例通过率 100%。
2. P1 用例通过率 >= 95%，且无阻塞缺陷。
3. 核心回归链路全绿。
4. 无高危安全缺陷残留。
