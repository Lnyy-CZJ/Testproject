# BugAgent v3.0 (Phase 3) Development Plan

> Date: 2026-04-09  
> Scope: 云效集成 + AI 配置数据库化 + 已发现问题修复闭环

---

## 1. Delivery Strategy

按“先修复已知问题、再做低风险基础能力、最后做外部集成”的顺序推进：

1. P0: 已知线上阻塞问题修复（5 项）
2. P1: AI 配置数据库化（后端表结构与读取路径）
3. P2: 云效凭证与适配层
4. P3: 云效仓库与成员导入
5. P4: 联调、压测、验收与发布

## 3. Work Breakdown (P1-P4)

## Phase P1: AI 配置数据库化（2-3 天）

目标：AI 厂商/模型由数据库维护，接口动态读取。

任务：
1. 新增迁移脚本：
   - `ai_provider_catalog`
   - `ai_model_catalog`
2. 新增模型与 DAO：
   - `server/internal/model/ai_catalog.go`
3. 改造 `GET /api/v1/ai/providers`：
   - 优先读目录表
   - 目录为空回退内置配置
4. 新增管理接口（admin）：
   - 厂商增删改查
   - 模型增删改查
5. 前端支持：
   - 保留下拉
   - 保留手动填写厂商/模型
   - 展示目录状态（active/deprecated）

完成标准：
1. 不改项目 AI 配置主表结构即可完成动态模型维护。
2. 目录增删改对项目配置页可见。

## Phase P2: 云效凭证与 SDK 适配层（2 天）

目标：可安全连接云效并标准化输出。

任务：
1. 扩展凭证 provider `yunxiao`，支持 `extra_config`。
2. 新增连通性测试接口 `POST /integrations/yunxiao/test-connection`。
3. 新建 `server/internal/integrations/yunxiao`：
   - HTTP client
   - token 注入
   - 错误码映射
   - 重试/超时控制
4. 新增审计日志埋点（创建、更新、测试）。

完成标准：
1. 云效凭证可创建并通过测试。
2. API 失败可返回可读错误信息。

## Phase P3: 云效仓库/成员导入（3-4 天）

目标：从云效导入仓库和成员，落到现有项目模型。

任务：
1. 仓库导入：
   - 拉取仓库列表接口（分页/搜索）
   - 批量导入接口
   - 去重策略（规范化 repoUrl）
2. 成员导入：
   - 拉取成员接口
   - 导入预览（新增/更新/跳过）
   - 角色映射策略
3. 前端：
   - 仓库页“从云效导入”弹窗
   - 成员页“从云效导入”弹窗
   - 导入结果摘要（成功/失败/跳过）
4. 权限控制：
   - 项目管理员及以上可操作

完成标准：
1. 可导入仓库与成员。
2. 重复导入不会产生重复数据。

## Phase P4: 联调、回归、发布（2 天）

任务：
1. 后端测试：
   - handler 单测
   - service 单测
   - 云效适配层 mock 测试
2. 前端验证：
   - 核心流程 e2e（登录->项目->凭证->导入->AI配置）
3. 性能检查：
   - 导入接口大数据量分页
   - 项目列表与缺陷列表查询回归
4. 发布准备：
   - 配置项检查
   - 回滚开关验证
   - 变更说明

完成标准：
1. 测试通过率 100%（本期范围）。
2. 核心链路可演示闭环。

## 4. Testing Plan

1. Unit:
   - 凭证与目录 CRUD
   - 云效响应解析与错误映射
2. Integration:
   - 云效导入仓库/成员全链路
   - AI 目录更新后项目配置页刷新可见
3. Regression:
   - 缺陷分析/修复/验证主流程
   - 项目与迭代切换
4. Frontend E2E:
   - 导入弹窗流程
   - 异常提示与重试

## 5. Milestones

1. M1 (Day 1): P0 问题修复完成并通过构建/测试。
2. M2 (Day 3): AI 目录数据库化完成，接口已切换。
3. M3 (Day 5): 云效凭证与仓库导入完成。
4. M4 (Day 7): 成员导入 + 全链路联调完成。
5. M5 (Day 8): 回归、验收、发布准备完成。

---

## 6. Risks And Mitigation

1. 云效 API 限流或字段变更：
   - 适配层做容错和重试，关键字段做降级兜底。
2. 用户体系映射不完整（云效成员未在本地注册）：
   - 提供未匹配列表与批量邀请入口。
3. AI 目录误操作导致可选模型为空：
   - 保留内置回退与手动填写。
4. 导入造成脏数据：
   - 导入预览 + 幂等去重 + 审计日志。

---

## 7. Definition Of Done

1. PRD 中 FR-1~FR-5 均有实现与验证证据。
2. P0 五个问题在测试环境可复测通过。
3. 文档、迁移、接口、前端交互一致。
4. 回滚方案可执行，关键开关可控。
