- 页面可进入，无白屏、无明显报错。
- 核心操作有明确成功或失败反馈。
- 列表与详情数据一致。

- `执行结果` 填写: `PASS / FAIL / BLOCKED`

  - 有问题时记录 `问题现象 + 触发步骤 + 期望行为`

1. 登录 -> 项目列表 -> 个人中心 -> 通知中心

4. 项目通知 -> AI 配置 -> AI 目录
