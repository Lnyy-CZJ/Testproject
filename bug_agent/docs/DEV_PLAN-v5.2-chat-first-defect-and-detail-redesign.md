# BugAgent v5.2 Development Plan

> Date: 2026-04-13
> Scope: Chat-first 缺陷创建 + 手动缺陷进入问题池 + 缺陷详情页重构

---

## 1. Delivery Strategy

本期按“先改入口，再统一模型，最后重构阅读体验”的顺序推进：

1. `P1` 对话式创建缺陷
2. `P2` 手动缺陷进入问题池
3. `P3` 缺陷详情页重构

说明：

1. `P1` 是本期主功能，直接解决创建成本问题。
2. `P2` 保证新入口不会继续制造双轨数据模型。
3. `P3` 在前两项稳定后重构缺陷阅读和处理体验。

---

## 2. Ordered Worklist

### P1 对话式创建缺陷

目标：让用户用自然语言发起缺陷，并由 AI 生成结构化草稿。

任务：

1. 新建缺陷默认入口改为 `对话创建缺陷`。
2. 实现 chat-first 输入区和附件补充。
3. 新增 AI 草稿生成接口。
4. 实现确认页与字段可编辑能力。
5. 保留 `高级模式` 次级入口。
6. 增加 AI 失败降级到最小草稿逻辑。
7. 增加对应自动化测试和浏览器回归。

完成标准：

1. 用户可通过对话生成结构化缺陷草稿。
2. 用户确认前不会落正式缺陷。
3. AI 失败时仍可继续创建。

### P2 手动缺陷进入问题池

目标：让所有手工创建缺陷自动进入统一问题池模型。

任务：

1. 为手工缺陷创建 `manual_chat / manual_form` 来源类型。
2. 在确认创建时自动生成 signal。
3. 自动创建或关联 cluster。
4. 建立 defect 与 cluster 双向关联。
5. 问题池增加手工来源显示与跳转。
6. 质量情报和回归预防覆盖手工来源。
7. 增加唯一约束与重复保护。
8. 补 handler / service / e2e 回归。

完成标准：

1. 所有手动缺陷进入问题池。
2. 不会重复生成 signal。
3. 手工来源可进入问题治理与统计。

### P3 缺陷详情页重构

目标：把当前详情页改成真正可读的处理工作台。

任务：

1. 重构页面整体布局为顶部摘要 + 中部双栏 + 底部折叠区。
2. 接入 GFM Markdown 渲染。
3. 统一 AI 分析摘要卡结构。
4. 评论区改为时间线。
5. 原始 JSON、调试信息折叠展示。
6. 修复任务卡简化和默认折叠。
7. 历史评论/分析内容渲染兼容处理。
8. 补浏览器回归和视觉检查。

完成标准：

1. Markdown 正确渲染。
2. 正文信息层级清晰。
3. 系统和 AI 长消息不再直接淹没页面。

---

## 3. Suggested Engineering Split

### Backend

1. 缺陷草稿生成接口
2. 缺陷确认创建接口
3. `manual signal / cluster` 自动建模
4. 缺陷详情结构化摘要与原始数据接口补强
5. 唯一约束与回归测试

### Frontend

1. chat-first 创建页面
2. 确认页与高级模式切换
3. 问题池手工来源展示
4. 缺陷详情布局重构
5. Markdown / timeline / raw-data 折叠展示

### QA / Integration

1. 对话创建主链路回归
2. AI 失败降级回归
3. 手动来源问题池联调
4. 缺陷详情渲染与状态流转回归

---

## 4. Testing Scope

必须覆盖：

1. 对话输入 -> 草稿 -> 确认 -> 创建缺陷
2. AI 失败 -> 最小草稿 -> 继续创建
3. 高级模式 -> 创建缺陷 -> 自动生成 `manual_form`
4. 对话模式 -> 创建缺陷 -> 自动生成 `manual_chat`
5. 问题池可查看手工来源并跳转正式缺陷
6. 质量情报统计包含手工来源
7. 缺陷详情 Markdown 渲染
8. 长评论折叠与展开
9. 原始 JSON 折叠展示
10. 状态流转和自动修复入口未被布局改造破坏

---

## 5. Exit Criteria

1. 新建缺陷默认采用 chat-first。
2. AI 草稿生成与确认页可稳定使用。
3. 所有手动缺陷自动进入问题池。
4. 问题池和质量情报支持手工来源。
5. 缺陷详情页 Markdown 渲染与布局重构完成。
6. 关键浏览器回归与后端自动化测试通过。
