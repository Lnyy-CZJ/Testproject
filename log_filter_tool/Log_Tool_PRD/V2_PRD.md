# Log 工具 V2 单次请求链路 PRD

## 一、产品定位

在 V1.5 接口统计的基础上，通过 `request_id` 和 `trace_id` 关联一次接口调用的请求、响应及相关日志，帮助测试工程师查看单次调用的完整链路。

## 二、背景与目标

V1.5 可以统计接口整体情况，但无法区分同一个接口的多次调用，也无法快速确认某个请求对应的响应。

V2 需要建立“单次调用记录”，支持查看请求和响应之间的关系，包括请求时间、请求参数、响应时间、响应数据、状态码、关联 ID、耗时和结果。

## 三、用户场景

### 3.1 查看接口的多次调用

用户选择 `TrackEvents`，系统列出每次调用的时间、状态码、耗时和结果。

### 3.2 根据 request_id 排查

测试人员拿到一个 `request_id`，直接搜索并查看对应请求、响应和相关日志。

### 3.3 根据 trace_id 查看链路

用户输入 `trace_id`，查看同一链路下的相关日志。

## 四、功能需求

### 4.1 调用记录

每次调用记录包含：

```python
{
    "call_id": "内部编号",
    "method": "TrackEvents",
    "request_id": "abc123",
    "trace_id": "trace456",
    "request": {},
    "response": {},
    "related_logs": [],
    "result": "success"
}
```

### 4.2 请求和响应关联规则

关联优先级：

1. `request_id` 相同。
2. `trace_id` 相同。
3. method 相同且响应时间晚于请求时间。
4. 请求和响应日志块相邻或距离较近。

使用第 3 或第 4 种方式推断时，页面必须标记“推测关联”。

### 4.3 不完整关联

- 有请求没有响应：标记“未找到响应”。
- 有响应没有请求：标记“未找到请求”。
- 缺少关键字段：标记“信息不完整”。
- 无法判断关联关系：标记“关联不确定”。

### 4.4 调用状态

支持以下状态：

- `success`：请求和响应完整，HTTP 状态码成功。
- `http_failed`：HTTP 状态码大于等于 400。
- `no_response`：有请求但没有响应。
- `incomplete`：请求或响应信息不完整。
- `unknown`：无法判断结果。

业务失败和超时规则在 V3 中完善。

### 4.5 链路耗时

如果可以提取请求时间和响应时间，则计算响应时间减请求时间，并展示单次调用耗时、接口平均耗时、最大耗时和最小耗时。

时间无法解析时显示“耗时未知”，不能影响其他功能。

### 4.6 相关日志

相关日志包括请求头、请求体、响应头、响应体、相同 `request_id` 或 `trace_id` 的日志，以及请求和响应之间的上下文日志。

原始日志顺序必须保持不变。

## 五、页面设计

增加“请求链路”视图：接口选择、调用记录列表和调用详情。

调用记录列表示例：

| 时间 | Request ID | 状态 | HTTP 状态码 | 耗时 |
|---|---|---|---:|---:|
| 17:17:58 | abc123 | 成功 | 200 | 447ms |
| 17:18:02 | abc124 | 失败 | 500 | 830ms |
| 17:18:05 | abc125 | 未响应 | - | - |

调用详情包含基本信息、请求信息、响应信息、关联方式、关联日志和原始日志。

## 六、搜索和筛选

支持：

- 按 method 搜索。
- 按 `request_id` 搜索。
- 按 `trace_id` 搜索。
- 按调用状态筛选。
- 按 HTTP 状态码筛选。

暂不支持复杂查询表达式。

## 七、验收标准

1. 相同 `request_id` 的请求和响应可以正确关联。
2. 没有 `request_id` 时可以使用 `trace_id` 关联。
3. 同一个 method 的多次调用可以区分。
4. 可以列出一个接口的多次调用记录。
5. 可以查看单次调用的请求和响应。
6. 可以显示单次调用耗时。
7. 请求没有响应时显示“未找到响应”。
8. 响应没有请求时显示“未找到请求”。
9. 推断关联时明确显示“推测关联”。
10. 原始日志顺序不会被破坏。

## 八、非目标

- 分布式 Trace 协议接入。
- OpenTelemetry 接入。
- 跨机器实时追踪。
- 数据库存储。
- 自动重试接口。
- 复杂链路图可视化。
