# 候选结果模块字段整理

五个业务模块字段。

| 模块 | 字段 | 中文含义 | 来源路径/生成规则 | 内容格式 |
|---|---|---|---|---|
| Insights | `insights_status` | Insights 模块返回状态 | `results[].ui_sections.insights.status` | 枚举文本或空值，如 `data`、`empty` |
| Insights | `insights_description` | 第一条 Insight 的描述 | `results[].ui_sections.insights.data.items[0].description` | 普通文本或空值 |
| Insights | `insights_links` | 第一条 Insight 的证据链接 | `results[].ui_sections.insights.data.items[0].links` | 多行文本，每条为 `title：url`；缺少 title 时只保留 URL |
| Photos | `photos_status` | Photos 模块返回状态 | `results[].ui_sections.photos.status` | 枚举文本或空值，如 `data`、`empty` |
| Photos | `photos_baseline_photo_url` | 基准照片地址 | `results[].ui_sections.photos.data.baseline_photo_url` | URL 文本或空值 |
| Photos | `photos_identity_match_rate` | 照片身份匹配率 | `results[].ui_sections.photos.data.identity_match_rate` | 数值或空值 |
| Photos | `photos_authenticity_photos` | 真实性照片集合 | `results[].ui_sections.photos.data.authenticity_photos` | JSON 数组文本；超长内容转存 Raw 数据 |
| Photos | `photos_match_photos` | 匹配照片集合 | `results[].ui_sections.photos.data.match_photos` | JSON 数组文本；超长内容转存 Raw 数据 |
| Profile | `profile_status` | Profile 模块返回状态 | `results[].ui_sections.profile.status` | 枚举文本或空值，如 `data`、`empty` |
| Profile | `profile.Identity.Full Name` | 姓名 | Profile 中 `Identity / Full Name` 对应的 value | 文本；重复值换行 |
| Profile | `profile.Identity.Age` | 年龄 | Profile 中 `Identity / Age` 对应的 value | 文本或数字文本；重复值换行 |
| Profile | `profile.Identity.Location` | 所在地 | Profile 中 `Identity / Location` 对应的 value | 文本；重复值换行 |
| Profile | `profile.Identity.Email` | 邮箱 | Profile 中 `Identity / Email` 对应的 value | 邮箱文本；重复值换行 |
| Profile | `profile.Identity.Profile URL` | 个人资料页面 | Profile 中 `Identity / Profile URL` 对应的 value | URL 文本；重复值换行 |
| Profile | `profile.Career.Current Role` | 当前职位 | Profile 中 `Career / Current Role` 对应的 value | 文本；重复值换行 |
| Profile | `profile.Background.Education` | 教育经历 | Profile 中 `Background / Education` 对应的 value | 文本；重复值换行 |
| Profile | `profile.Career.Other Roles` | 其他职位 | Profile 中 `Career / Other Roles` 对应的 value | 文本；重复值换行 |
| Social | `social_status` | Social 模块返回状态 | `results[].ui_sections.social.status` | 枚举文本或空值，如 `data`、`empty` |
| Social | `social_display_handles` | 社交账号展示名 | `results[].ui_sections.social.data.profiles[].display_handle` | 多行文本，每个账号一行 |
| Social | `social_platforms` | 社交平台 | `results[].ui_sections.social.data.profiles[].platform` | 多行文本，与账号逐行对应 |
| Social | `social_urls` | 社交主页地址 | `results[].ui_sections.social.data.profiles[].url` | 多行 URL，与账号逐行对应 |
| Summary | `summary_avatar_url` | 候选人头像地址 | `results[].ui_sections.summary.data.avatar_url` | URL 文本或空值 |
| Summary | `summary_confidence_level` | 系统置信等级 | `results[].ui_sections.summary.data.confidence_level` | 枚举文本或空值，如 `HIGH`、`LOW` |
| Summary | `summary_primary_image_url` | 主图地址 | `results[].ui_sections.summary.data.primary_image.url` | URL 文本或空值 |
| Summary | `summary_social_links` | 汇总后的社交链接 | `results[].ui_sections.summary.data.social_links` | 多行文本，每条为 `title：url`；缺少 title 时只保留 URL |
| Summary | `summary_web_links` | 汇总后的网页链接 | `results[].ui_sections.summary.data.web_links` | 多行文本，每条为 `title：url`；缺少 title 时只保留 URL |
