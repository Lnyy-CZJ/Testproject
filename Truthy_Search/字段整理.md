# UI Sections 完整字段整理

本文档以提供的 `ui_sections` 样例为准，按 JSON 中的模块顺序整理五个模块的所有已出现字段。

字段路径统一以候选人详情为起点：`results[].ui_sections`。`当前 Excel 列` 为当前候选结果表的导出状态；`—` 表示该字段当前未单独导出。

通用约定：

- `[]` 表示数组中的每个元素。
- JSON 样例中的空数组只记录数组字段本身；因没有元素，不能推断其内部对象结构。
- `Profile` 的字段是动态生成的：由 `sections[].title + items[].label` 组合为 `profile.<Section>.<Label>`。
- `generate_time` 与 `report_expires_at` 是 Unix Epoch 毫秒时间戳。

## 3. Profile

| 原始字段路径 | 中文说明 | 内容格式 | 当前 Excel 列 |
|---|---|---|---|
| `profile.status` | Profile 模块状态 | 枚举文本，如 `data`、`empty` | `profile_status` |
| `profile.data.sections[].title` | Profile 分组标题，例如 `Identity`、`Career` | 文本 | 用于生成动态列名 |
| `profile.data.sections[].items[].label` | 分组内字段标签，例如 `Full Name` | 文本 | 用于生成动态列名 |
| `profile.data.sections[].items[].value` | 字段实际值 | 文本、数字文本或 URL | 写入对应动态列 |

样例中实际出现的动态列：

| 原始来源 | 当前 Excel 列 | 中文说明 |
|---|---|---|
| `sections[title=Identity].items[label=Full Name].value` | `profile.Identity.Full Name` | 姓名 |
| `sections[title=Identity].items[label=Age].value` | `profile.Identity.Age` | 年龄 |
| `sections[title=Identity].items[label=Location].value` | `profile.Identity.Location` | 所在地 |
| `sections[title=Identity].items[label=Email].value` | `profile.Identity.Email` | 邮箱 |
| `sections[title=Identity].items[label=Profile URL].value` | `profile.Identity.Profile URL` | 个人资料 URL |
| `sections[title=Career].items[label=Current Role].value` | `profile.Career.Current Role` | 当前职位 |
| `sections[title=Background].items[label=Education].value` | `profile.Background.Education` | 教育经历 |

`profile.Career.Other Roles` 已在其他历史结果中出现；其来源同样遵循 `sections[title=Career].items[label=Other Roles].value`，但不在本次提供的样例中。

## 6. 当前导出覆盖范围

当前候选结果表已单独导出 26 个字段：

- Insights：状态、第一条描述、第一条链接。
- Photos：状态、基准照片、匹配率、两类照片集合。
- Profile：状态与所有当前样例中已出现的动态 `Section / Label` 字段。
- Social：公开账号的展示名、平台、URL；未导出用户名和 `private_accounts`。
- Summary：头像、置信等级、主图 URL、社交链接和网页链接；其余摘要字段目前仅保留在原始 JSON 中。
